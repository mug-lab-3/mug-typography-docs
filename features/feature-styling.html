使い方を見る設定リファレンス

縁取りをつける ​

  1. Page を Global Settings にします。
  2. Stroke 内の Width を上げて、内側の輪郭線（Inner Stroke）を表示します。
  3. Color、Join Style、Order を仕上がりに合わせて選びます。

設定見た目への影響
Join Style角を鋭く、丸く、面取り状に切り替える
Miter Limit鋭い角が長く伸びすぎるのを抑える
Order塗りとストロークのどちらを前面にするか決める
Gap塗りとストロークの間隔を空ける
Outer WidthInner Strokeの外側に隣接する2本目の輪郭線を追加する
Outer ColorOuter Strokeの色を指定する

TIP

Gap を上げると、塗りとストロークの間に透明な隙間を作れます。Transparent Fill と組み合わせれば、輪郭だけの中抜き文字になります。

2重ストロークを使う ​

  1. Width を 0.0 より大きくしてInner Strokeを表示します。
  2. Outer Width を上げて、Inner Strokeの外側に2本目の輪郭線を追加します。
  3. Color と Outer Color に異なる色を指定します。
  4. 必要に応じて Gap を上げ、文字本体と最も内側にある有効なStrokeの間を空けます。

Inner Stroke と Outer Stroke は、それぞれの太さ（Width / Outer Width）を 0 より大きくすると表示されます。両方を有効にすると、Inner Stroke のすぐ外側に Outer Stroke が重なります。Inner Stroke が 0 で Outer Stroke だけを有効にした場合は、文字本体と Outer Stroke の間に Gap が入ります。

特定の文字だけ縁取りを変えたいときは、Character Settings の Use Indiv Stroke を ON にすると、文字ごとに Stroke Width、Stroke Gap、Stroke Color、Outer Stroke Width、Outer Stroke Color を個別に設定できます。

文字をぼかす・発光させる（Blur / Glow） ​

  1. Page を Global Settings にします。
  2. Blur グループ内の Blur X / Blur Y を上げて、文字そのもの（塗り・グラデーション・テクスチャ・輪郭線）をぼかします。
  3. 発光させたい場合は Glow を上げます。ぼかした文字が明るく持ち上がり、値を上げるほど芯の部分が白に近づきます（ぼかしが 0.0 のときは効果がありません）。
設定見た目
Blur X / Y（ぼかしのみ）
Blur X / Y ＋ Glow（発光）

シャドウで奥行きや後光をつける ​

  1. Page を Global Settings にします。
  2. Shadow Settings 内の Draw Global Shadow を ON にします。
  3. Distance と Angle で影の距離と向きを決めます。
  4. 影を柔らかくぼかすには Blur X / Blur Y を上げ、ネオンのような後光（アウターグロー）にするには Glow を上げます（Distance を 0.0 にすると文字の真後ろで発光します）。
設定見た目
通常のシャドウ（ぼかしなし）
Blur X / Y（ぼかしシャドウ）
Blur X / Y ＋ Glow（発光シャドウ）

TIP

特定の文字だけ影の色を変えたいときは、Character Settings の Use Indiv Shadow Color を ON にします。Draw Global Shadow が OFF のときでも、このチェックを入れた文字だけに影を付けることができます。

背景ボックスを敷く ​

  1. Page を Global Settings にします。
  2. Bounding Box Settings 内の Draw Bounding Box を ON にします。
  3. 背景を塗りつぶす場合は Fill Background を ON にし、Fill Color と Fill Opacity を設定します。
  4. Margin X / Margin Y で文字周りの余白を調整します。Border Offset / Fill Offset を使うと、枠線や背景塗りの位置をあえてずらしたデザインを作れます。
  5. 枠線の有無や太さは Top / Bottom / Left / Right Edge と Border Width で調整します。

NOTE

角丸（Corner Radius）は、背景の塗りには枠線の有無にかかわらず適用されます。 一方、枠線自体に角丸が適用されるのは Top / Bottom / Left / Right のすべての Edge が ON の場合のみで、一部の辺を OFF にすると、枠線は直角のまま描画されます。
