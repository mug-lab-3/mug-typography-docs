LAYOUT & INTERACTION

文字のパーツまで思いどおりに動かす

テキストを文字単位、さらに文字を構成するパーツ単位まで分解。タイトルの一部だけを傾ける、濁点だけを飛び出させるといった緻密な演出を、ビューア上で直接デザインできます。

  • ビューアで直接操作
  • 文字・パーツ単位
  • マーキーで複数選択
使い方を見る設定リファレンス

使い方 ​

  1. Inspector 上部の Selection Mode を、動かしたい対象に合わせて選びます（テキスト全体は Global、文字は Character、文字内のパーツは Part）。
  2. ビューアで動かしたい対象をクリックします。複数選択するには、空白からマーキーをドラッグするか、WinCtrl+Alt/MacCommand+Option + クリックで対象を1つずつ追加・解除します。
  3. 対象をドラッグして移動します。
  4. 選択済みの対象を WinCtrl/MacCommand + クリックし、ハンドルで回転・スケール・ピボットを調整します。
  5. 数値を追い込みたい場合は、Page を選択モードに対応する設定ページ（Global Settings / Character Settings / Part Settings）に切り替えます。

TIP

ビューアで大まかに配置し、Inspector で数値を整えると効率的です。ビューア操作と Inspector の値は同じパラメーターを編集します。

文字とパーツの使い分け ​

やりたいことSelection Mode編集ページ
フォントやテキスト全体を調整するGlobalGlobal Settings
特定の文字だけを調整するCharacterCharacter Settings
文字内の点や画を調整するPartPart Settings

Part は通常版プリセット専用です。Lite版では Part Settings と Part 選択モードが表示されません。Scripting プリセットでは Character / Part の両方が表示されず、Lua スクリプトから個別の値を動かします。Inspector 上でパーツ単位の調整をしたい場合は、通常版プリセットを選んでください。

TIP

Lite版で作り始めたあとにパーツ編集が必要になった場合も、最初から作り直す必要はありません。通常版のインスタンスを新しく追加し、「コピー・ペースト」の Copy / Paste Entire Instance Settings で Lite版の設定をコピー＆ペーストすれば、デザインをそのまま引き継げます。ただしコピーされるのは現在フレームの値のみで、キーフレームアニメーションは引き継がれないため、アニメーションは切り替え後に付け直してください。

NOTE

Output Settings の Output Separation で現在の出力対象から外れている文字やパーツは、ビューアからも選択できません。
