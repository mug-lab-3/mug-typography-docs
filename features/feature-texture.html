文字に質感をまとわせる

水滴、ラメ、虹色、ステンドグラス。組み込みのマテリアルを選ぶだけで、平坦な塗りが素材感のある表面に変わります。下地の色やグラデーションはそのまま活かされます。

  • 8種類のマテリアル
  • 4つのつまみで調整
  • 下地の色を活かす
使い方を見る設定リファレンス

使い方 ​

  1. Page を Global Settings にします。
  2. Color Settings の Texture グループを開きます。
  3. Texture でマテリアルを選びます。
  4. P1〜P4（選んだマテリアルに応じて名前が変わります）で質感を調整します。
  5. Texture Color で色を調整します。

マテリアルごとの違い ​

Water Droplet（水滴）
マテリアル特徴
Water Droplet文字が水を含んでぷっくりと盛り上がり、表面に光沢が乗ります。窓ガラスを流れる水滴や、濡れたゼリーのような見た目です
Air Cushion縁が圧着され、内側が膨らんだフィルム。空気で膨らませた包装材のような質感です
Glitter細かな金属片を密に重ね、光の方向に合った粒がきらめきます。ストロークの上にも乗ります
Iridescent薄膜干渉による虹色。見る角度で色が変わる、シャボン玉や玉虫色の質感です
Faceted表面を多面体に分割し、面ごとに光の当たり方を変えます。岩肌やローポリの地形のような、ごつごつした見た目です
Stained Glass塗りを色ガラスの断片に分割し、鉛線で縁取ります
Metallic塗り色をそのまま金属の反射色として磨き上げます。黄土色なら金、明るい灰色なら銀、赤茶色なら銅に見えます
Metallic 2Metallic と同じ金属ですが、ハイライトがくっきり立ち、全体が明るく出ます。Exposure で明るさそのものを調整できます

Light Angle だけは角度（0〜360）で、それ以外はすべて 0〜1 です。Stained Glass の Glow は同じ第4スロットですが角度ではなく、中央の 0.5 が素のガラス、上げると発光、下げると暗くなります。

下地の色を活かす ​

マテリアルは塗りを置き換えるのではなく、その上に重ねて描かれます。Font Color やグラデーション、文字ごとの個別色がそのまま下地として残るため、色の選び方が仕上がりに直結します。

ただし色の決まり方はマテリアルによって違います。Stained Glass は下地の色相を起点に各ガラス片の色を決めるため、下地の色がそのまま作品の色調になります。一方 Glitter の金属片は Texture Color を基本色とし、下地ではなくそちらで色を決めます。

TIP

Stained Glass をグラデーションと組み合わせると、位置によってガラス片の色が変わります。単色では作りにくい表情が出せます。

組み合わせのレシピ ​

金色に輝くラメ

  1. Texture を Glitter にします
  2. Texture Color を金色にします。金属片の基本色になります
  3. Flake Amount（P3）で粒の密度を決めます
  4. Highlight Ratio（P2）を上げると、強く光る粒が増えます
  5. Light Angle（P4）にキーフレームを打つと、光る粒が入れ替わってきらめきが動きます

単色ガラスから多色ガラスへ

  1. Texture を Stained Glass にします
  2. Hue Range（P3）を 0 にすると、塗りの色相を保った単色のガラスになります
  3. Hue Range に 0 から 1 へのキーフレームを打つと、色が広がっていくアニメーションになります

スクリプトからの制御 ​

ctx.global.texture でマテリアルとコントロールを設定できるほか、ctx.chars[i].texture / ctx.parts[i].texture に use = true を指定すると、文字やパーツ単位で別のマテリアルに差し替えられます。詳しくは「Luaスクリプトで動かす」を参照してください。

思ったとおりにならないとき ​

  • マテリアルが何も出ない — Transparent Fill がONになっていないか確認してください。塗り自体が描かれなくなるため、その上に重なるマテリアルも消えます（個別カラーを指定した文字・パーツだけは残ります）。
  • Texture Color を変えても色が変わらない — Iridescent を選んでいませんか。このマテリアルは薄膜干渉そのものから色が決まるため、Texture Color を無視します。
  • MT Sim と実際の描画が違う — MT Sim（VSCode拡張）のテクスチャ表示は簡易的なプレビューです。マテリアルの選択とコントロールの効きは確認できますが、最終的な見た目はプラグイン本体で確認してください。
