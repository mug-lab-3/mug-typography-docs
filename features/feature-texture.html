文字に質感をまとわせる

水滴、ラメ、虹色、ステンドグラス。組み込みのマテリアルを選ぶだけで、平坦な塗りが素材感のある表面に変わります。下地の色やグラデーションはそのまま活かされます。

  • 13種類のマテリアル
  • 最大5つのつまみで調整
  • 下地の色を活かす
使い方を見る設定リファレンス

使い方 ​

  1. Page を Global Settings にします。
  2. Color Settings の Texture グループを開きます。
  3. Texture でマテリアルを選びます。
  4. P1〜P5（選んだマテリアルに応じて名前が変わります。P5は、使うマテリアルを選んだときだけ表示されます）で質感を調整します。
  5. Texture Color で色を調整します。

マテリアルごとの違い ​

Water Droplet（水滴）
マテリアル特徴
Water Droplet文字が水を含んでぷっくりと盛り上がり、表面に光沢が乗ります。窓ガラスを流れる水滴や、濡れたゼリーのような見た目です。
Air Cushion縁が圧着され、内側が膨らんだフィルム。空気で膨らませた包装材のような質感です。
Glitter細かな金属片を密に重ね、光の方向に合った粒がきらめきます。ストロークの上にも乗ります。
Iridescent薄膜干渉による虹色。見る角度で色が変わる、シャボン玉や玉虫色の質感です。Film Variation を上げると、膜厚のムラで油膜のように色が流れます。
Faceted石に彫った文字のように、輪郭から内側へ傾いた平らな面で文字を切り出します。面はまっすぐな稜線で合わさり、くっきりと光と影に分かれます。
Stained Glass塗りを色ガラスの断片に分割し、鉛線で縁取ります。
Metallic研磨の筋が走るヘアライン仕上げの金属です。塗り色がそのまま金属の色になり、黄土色なら金、明るい灰色なら銀、赤茶色なら銅に見えます。Hairline Angle で筋の向きを変えられます。
Metallic 2空と地平線が映り込むクロームメッキです。くっきりした明暗の切り替わりで強く光ります。Exposure で明るさそのものを調整できます。
Stripe塗りの上に、指定した色の平行な縞を重ねます。縞の本数・太さ・角度・濃さを調整できます。
Colored Pencilベタ塗りの塗り色に、白い細い線（塗り残し）が不規則に散ります。光の当たる側の縁は白く塗り残され、色鉛筆で白い紙に塗ったような見た目になります。下地の塗り色が鉛筆の色、Texture Color が紙の色です。
Halftone塗りの上に、指定した色の丸い網点を格子状に並べます。Fade を上げると点が小さくなっていき、Fade Angle で小さくなる向きを決められます（0 で下へ向かって濃くなります）。
Halftone DiamondHalftone と同じ網点を、ひし形の点で並べます。点の大きさは丸と同じ面積で揃うので、切り替えても濃さは変わりません。
Prism Foil塗りを銀色のプリズム箔に置き換えます。正方形のタイルの中心から光の筋と虹色が放射状に広がる、ホログラムのシールのような見た目です。Light Angle を動かすと、光を受けるタイルと筋が移り変わります。

角度（0〜360）のコントロールは Light Angle・Stripe Angle・Grid Angle・Fade Angle・Stroke Angle で、それ以外はすべて 0〜1 です。Stained Glass の Glow は同じ第4スロットですが角度ではなく、中央の 0.5 が素のガラス、上げると発光、下げると暗くなります。

下地の色を活かす ​

マテリアルは塗りを置き換えるのではなく、その上に重ねて描かれます（Prism Foil だけは例外で、下の段落を参照してください）。Font Color やグラデーション、文字ごとの個別色がそのまま下地として残るため、色の選び方が仕上がりに直結します。

ただし色の決まり方はマテリアルによって違います。Stained Glass は下地の色相を起点に各ガラス片の色を決めるため、下地の色がそのまま作品の色調になります。一方 Glitter の金属片は Texture Color を基本色とし、下地ではなくそちらで色を決めます。

Stripe・Halftone・Halftone Diamond は、縞や点を Texture Color で描きます。Colored Pencil は逆に、下地の塗り色が鉛筆の色になり、Texture Color は塗り残しの白い線の色（紙の色）です。

Prism Foil は塗りを箔で置き換えるため、下地の色は Strength を下げたときにだけ透けて見えます。箔の色は Texture Color で決まり、既定の白で銀、黄色寄りにすると金の箔になります。

TIP

Stained Glass をグラデーションと組み合わせると、位置によってガラス片の色が変わります。単色では作りにくい表情が出せます。

組み合わせのレシピ ​

金色に輝くラメ

  1. Texture を Glitter にします。
  2. Texture Color を金色にします。金属片の基本色になります。
  3. Flake Amount（P3）で粒の密度を決めます。
  4. Highlight Ratio（P2）を上げると、強く光る粒が増えます。
  5. Light Angle（P4）にキーフレームを打つと、光る粒が入れ替わってきらめきが動きます。

単色ガラスから多色ガラスへ

  1. Texture を Stained Glass にします。
  2. Hue Range（P3）を 0 にすると、塗りの色相を保った単色のガラスになります。
  3. Hue Range に 0 から 1 へのキーフレームを打つと、色が広がっていくアニメーションになります。

スクリプトからの制御 ​

ctx.global.texture で全体のマテリアルとコントロールを設定できるほか、ctx.chars[i].texture / ctx.parts[i].texture に use = true を指定すると、文字やパーツ単位で別のマテリアルに差し替えられます（文字・パーツ単位での別マテリアル指定はLuaスクリプトからのみ行えます）。詳しくは「Luaスクリプトで動かす」を参照してください。

思ったとおりにならないとき ​

  • マテリアルが何も出ない - Transparent Fill がONになっていないか確認してください。塗り自体が描かれなくなるため、その上に重なるマテリアルも消えます（個別カラーを指定した文字・パーツだけは残ります）。
  • Texture Color を変えても色が変わらない - Iridescent を選んでいませんか。このマテリアルは薄膜干渉そのものから色が決まるため、Texture Color を無視します。
  • Colored Pencil の線が出ない - Scratch Density（P1）が 0 になっていないか確認してください。0 では白い線が出ません。光の当たる縁の塗り残しは Light Amount（P3）で決まるため、0 にすると、それも出ません。
  • Prism Foil に下地の色が出ない - 箔が塗りを置き換えるためです。下地の色を混ぜたいときは Strength（P3）を下げてください。
  • MT Sim と実際の描画が違う - MT Sim（VSCode拡張）のテクスチャ表示は簡易的なプレビューです。Colored Pencil では、光に面した縁の塗り残しを表示しません。Prism Foil は、タイルの中の光の筋を少数の扇形に分けて塗るため、筋の境目が角張って見えます。Iridescent の Film Variation は表示に反映されません。マテリアルの選択とコントロールの効きは確認できますが、最終的な見た目はプラグイン本体で確認してください。
