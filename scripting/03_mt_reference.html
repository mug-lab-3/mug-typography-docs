mt.keyframes(keys, time) ​

APIレベル: 1+

複数区間のキーフレームを評価します。ctx.timeから直接呼べるため、 落下→バウンド→静止のような多段の振り付けを clamp + inverse_lerp の手書きなしで書けます。

引数 ​

引数型単位省略時内容
keystable[]—指定必須キーフレームの配列。各要素は{ t = <時刻>, v = <値>, ease = <省略可> }で、tを昇順に並べます
timenumber秒指定必須評価する時刻

各キーの v は number または { r, g, b, a } 形式の color テーブルのいずれかで、1つの keys 配列内で混在させることはできません。ease は省略可(既定は線形)で、そのキーへ到達するまでの 区間に適用されます。mt.ease.out_bounce のような名前の文字列、または function(t) ... end の 形の任意のイージング関数を渡せます。

time が最初のキーより前なら最初の値、最後のキーより後なら最後の値を返します(クランプ)。

戻り値 ​

型単位内容
number | colorキーの値と同じ区間内で補間された値

使用例 ​

lua
-- 0.0〜0.3秒でバウンドしながら落下し、0.3〜0.5秒は静止、
-- 0.5秒以降クリップ終端に向けてゆっくり退場する
local y = mt.keyframes({
    { t = 0.0, v = 1.2 },
    { t = 0.3, v = 0.5, ease = "out_bounce" },
    { t = 0.8, v = 0.5 },
    { t = 1.3, v = -0.2, ease = "in_cubic" },
}, ctx.time)

-- color もそのまま補間できる
local tint = mt.keyframes({
    { t = 0.0, v = { r = 1.0, g = 1.0, b = 1.0, a = 1.0 } },
    { t = 1.0, v = { r = 1.0, g = 0.4, b = 0.1, a = 1.0 } },
}, ctx.time)
character.fill.color = tint

3. 進行度の分配 ​

mt.distribute(index, count) ​

APIレベル: 1+

1始まりの index を 0–1 へ均等に割り付けます。先頭が 0、末尾が 1 になります。

引数 ​

引数型単位省略時内容
indexinteger—指定必須1始まりのindex。ctx.chars[index]のindexなどを渡します
countinteger—指定必須総数。ctx.char_countなどを渡します

戻り値 ​

型単位内容
number0–1(index - 1) / (count - 1)を0–1へ制限した値。count <= 1の場合は0

使用例 ​

lua
-- 文字位置に応じて色相を虹状に配置
local hue = mt.distribute(index, ctx.char_count)
character.fill.use = true
character.fill.color = mt.color.from_hsv(hue, 0.8, 1.0)

mt.each_char(ctx, options?) ​

APIレベル: 6+

整形済み文字を絞り込みつつ反復するイテレータを返します。index は常に ctx.chars 上のindexなので、ctx.chars[index] や mt.layout.* にそのまま渡せます。絞り込み後の通し番号は info.n です。

引数 ​

引数型単位省略時内容
ctxtable—指定必須OnLayout / OnPath の context
options.frominteger—1反復を開始する文字index
options.tointeger—ctx.char_count反復を終了する文字index（この値を含む）
options.lineinteger—絞り込みなしこの line_index の文字だけを通します
options.orderstring—"asc"info.progress の割り当て順。"asc" / "desc" / "center" / "random"
options.seedinteger—0order = "random" のときの並びを決めるseed

戻り値 ​

型内容
functionindex（ctx.chars上のindex）、character、info を返すイテレータ

info の各フィールド:

フィールド型内容
progressnumberorder に沿った 0–1 の正規化位置
ninteger絞り込み後の通し番号（1始まり）
countinteger絞り込み後の要素数（最低1）
first / lastboolean絞り込み後の先頭・末尾かどうか

order の割り当ては次の通りです（訪問順は常にindexの昇順で、変わるのは progress の値だけです）。

指定progress の並び（5要素の場合）
"asc"0, 0.25, 0.5, 0.75, 1
"desc"1, 0.75, 0.5, 0.25, 0
"center"1, 0.5, 0, 0.5, 1
"random"seedで決まる重複のない並び替え

"center" は中点からの距離を正規化した値です。要素数が偶数の場合は中点に要素が乗らないため、最小値は 0 になりません。

注意: info は毎回同じテーブルを使い回します。ループの外へ持ち出す場合は値をコピーしてください。

使用例 ​

lua
-- 2行目だけを、中央から外側へ順に開く
for index, character, info in mt.each_char(ctx, { line = 1, order = "center" }) do
    local delay = info.progress * 0.4
    character.opacity = mt.saturate((ctx.time - delay) * 4.0)
end

mt.each_part(ctx, options?) ​

APIレベル: 6+

整形済みパートを絞り込みつつ反復するイテレータを返します。mt.each_char と同じ規則に加えて、所属文字を info から直接参照でき、所属文字による絞り込みができます。

引数 ​

引数型単位省略時内容
ctxtable—指定必須OnLayout / OnPath の context
options.frominteger—1反復を開始するパートindex
options.tointeger—ctx.part_count反復を終了するパートindex（この値を含む）
options.from_charinteger—絞り込みなし所属文字のindexがこの値以上のパートだけを通します
options.to_charinteger—絞り込みなし所属文字のindexがこの値以下のパートだけを通します
options.lineinteger—絞り込みなしこの line_index のパートだけを通します
options.orderstring—"asc"info.progress の割り当て順。mt.each_char と同じ
options.seedinteger—0order = "random" のときの並びを決めるseed

from / to（パートindexの範囲）と from_char / to_char（所属文字indexの範囲）は別々の軸で、両方指定した場合は両方を満たすパートだけが通ります。

戻り値 ​

型内容
functionindex（ctx.parts上のindex）、part、info を返すイテレータ

info は mt.each_char の全フィールドに加えて次を持ちます。

フィールド型内容
charMtCharacterこのパートが属する文字（ctx.chars の要素）
char_indexinteger属する文字の ctx.chars 上のindex
index_in_charintegerその文字の中での位置

info.progress は絞り込み後の集合全体を通しで 0–1 に張ります。文字の境界でリセットはしません。文字ごとに 0–1 を張りたい場合は mt.each_char と mt.each_part を入れ子にしてください。

使用例 ​

lua
-- 3〜5文字目のパートだけを、通しで順に持ち上げる
for index, part, info in mt.each_part(ctx, { from_char = 3, to_char = 5 }) do
    part.offset_y = info.progress * 0.05
    part.rotation = info.char.rotation * 0.5
end

mt.stagger(time, index, delay, duration) ​

APIレベル: 1+

index ごとに開始をずらしたアニメーション進行度を返します。文字送りの定番関数です。 index i のアニメーションは delay * (i - 1) 秒遅れて始まり、duration 秒かけて 0から1へ進みます。

引数 ​

引数型単位省略時内容
timenumber秒指定必須アニメーション開始からの経過時間
indexinteger—指定必須1始まりのindex
delaynumber秒指定必須次のindexが開始するまでの遅延
durationnumber秒指定必須各indexのアニメーション時間

戻り値 ​

型単位内容
number0–10–1へクランプされた進行度

制約・エラー ​

条件内容
duration <= 00より大きい値を指定してください

使用例 ​

lua
for index = 1, ctx.char_count do
    local progress = mt.stagger(ctx.time, index, 0.08, 0.4)
    ctx.chars[index].offset_y = 0.5 + (1.0 - mt.ease.out_cubic(progress)) * 0.2
end

mt.stagger_progress(progress, position, span) ​

APIレベル: 6+

0–1へ正規化済みの全体進行度へ、要素位置に応じた開始時間差を付けます。 position = 0の要素は全体と同時に開始し、position = 1の要素は全体進行度が spanへ達した時点で開始します。すべての要素は全体進行度が1へ達した時点で完了します。

秒単位の時刻、index、要素ごとのdurationから進行度を作る場合はmt.staggerを使用します。 mt.timeline.intro_outro_secondsなどから得た既存の進行度を分散する場合は mt.stagger_progressを使用します。

引数 ​

引数型単位省略時内容
progressnumber0–1指定必須分散元の全体進行度。範囲外も許可され、戻り値が0–1へクランプされます
positionnumber0–1指定必須要素の正規化位置。範囲外は0–1へクランプされます。通常はinfo.progressを渡します
spannumber0–1未満指定必須全体時間のうち、開始時刻の分散に使用する割合

戻り値 ​

型単位内容
number0–1positionに対応する要素の進行度

戻り値は次の式で計算されます。

lua
mt.saturate((progress - mt.saturate(position) * span) / (1.0 - span))

制約・エラー ​

条件内容
progressまたはpositionが有限数ではないエラー
spanが有限数ではないエラー
span < 0またはspan >= 1エラー

使用例 ​

lua
local introProgress, outroProgress =
    mt.timeline.intro_outro_seconds(ctx, 0.5, 0.5, 5.0)

for _, character, info in mt.each_char(ctx, { order = "center" }) do
    local appear = mt.ease.out_back(
        mt.stagger_progress(introProgress, info.progress, 0.35))
    local disappear = mt.ease.in_cubic(
        mt.stagger_progress(outroProgress, info.progress, 0.25))

    character.scale = appear
    character.opacity = appear * (1.0 - disappear)
end

mt.each_char / mt.each_partのorderを変えると、ループの訪問順を変えずに 開始時間の割り当てだけを変更できます。

mt.stagger_pattern(time, index, count, pattern, delay, duration, seed?) ​

APIレベル: 1+

開始方向や順序を指定できるスタガー進行度を返します。

引数 ​

引数型単位省略時内容
timenumber秒指定必須評価する時刻
indexinteger—指定必須1始まりのindex
countinteger—指定必須総数。ctx.char_countなどを渡します
patternstring—指定必須進行パターン。"asc" / "desc"（別名"right_to_left"）/ "center" / "random"

戻り値 ​

number0–10–1へクランプされた進行度

制約・エラー ​

条件内容
duration <= 00より大きい値を指定してください

4. 距離による影響度 ​

mt.falloff(distance, radius) ​

APIレベル: 3+

中心で最大、離れるほどなだらかに弱まる影響度の重みを返します。戻り値は 0〜1 です。

引数 ​

引数型単位省略時内容
distancenumber入力座標系指定必須効果の中心からの距離
radiusnumber入力座標系指定必須減衰の広がり。この距離で重みが約0.37（e^-1）になります

「波の峰」「走る光沢」「注目箇所だけ強調」など、特定の位置を中心に効果を集中させる用途の定番です。

mt.smoothstep との使い分け: smoothstep は範囲外で完全に 0 になる（切れ目ができる）のに対し、falloff は裾が無限に続くため、峰や光が通り抜けていく動きが途切れずに見えます。線形減衰（1 - d/r）のような折れ曲がりも生じません。

戻り値 ​

型単位内容
number0–1距離に応じた影響度の重み

使用例 ​

lua
-- 波の先端 waveFront が通過した文字だけを持ち上げる
local distance = characterRadius - waveFront
character.offset_y = 0.5 + mt.falloff(distance, 0.25) * 0.1

NOTE

radius に 0 を渡した場合は 0 を返します(ゼロ除算を避けるため)。

5. 決定論的乱数・ノイズ ​

mt.random(seed, index, channel?) ​

APIレベル: 1+

(seed, index, channel) の組だけで値が決まる安定乱数です。呼び出し順に依存しないため、 文字・パーツごとのばらつきに安全に使えます(math.random は呼び出し順に依存するため この用途には使えません)。

APIレベル: 1+

減衰振動を評価します。t = 0で1から始まり、振動しながら0へ収束します。 「行き過ぎて揺れながら収まる」動きに使います。

引数 ​

引数型単位省略時内容
tnumber秒指定必須動き始めてからの経過時間。t <= 0では初期値を返します
frequencynumberHz指定必須1秒あたりの振動回数
dampingnumber1/秒指定必須減衰の強さ。大きいほど早く収束します

戻り値 ​

型単位内容
number—初期値1から0へ収束する減衰振動値

t > 0ではexp(-damping * t) * cos(2π * frequency * t)を計算します。

WARNING

戻り値は 0–1 に収まりません。 減衰中に 負の値（および、位相によっては 1 をわずかに 超えない範囲での行き過ぎ）を取り得ます。これはオーバーシュート表現そのものであり、 mt.ease.out_back / elastic が 0–1 の外へはみ出すのと同種です。

  • 向いている用途: offset / rotation / 散らばり量などの変位の残差 （例: 0.5 + settle * 0.1）
  • 向いていない用途: 進行度・opacity・scale / stretch へのそのままの代入や、 mt.lerp の t としての利用。進行度が必要なら mt.ease.* や mt.saturate を使い、 負値をそのまま倍率に掛けないでください（stretch はホスト側の下限クランプがなく、 負のまま描画に渡り得ます。scale は正の下限へクランプされ、opacity は描画直前に 0–1 へクランプされます）

使用例 ​

lua
-- 目標位置からのずれとして使う(t=0で最大、時間とともに収束。負の区間が行き過ぎ)
local settle = mt.spring(ctx.time - start_time, 3.0, 4.0)
character.offset_y = 0.5 + settle * 0.1

mt.impact_squash(config) ​

APIレベル: 3+

衝突の瞬間に潰れて弾む Squash & Stretch のインパルスを計算します。sin(ωt) * exp(-γt) の減衰振動で、衝突直後に最も潰れ、揺れながら元の形へ戻ります。

mt.bounce_* は Squash & Stretch を内部で適用済みなので、この関数は自前のタイミングで衝突を表現したいときに使います（他の文字にぶつかる、地面以外に当たる、など）。

引数 ​

引数型単位省略時内容
configtable—指定必須衝突時刻と変形特性の設定

config ​

フィールド型単位省略時内容
tnumber秒0.0現在時刻。impact_time未満では無変形の値を返します
impact_timenumber秒0.0衝突時刻。mt.bounce_*のlast_impact_timeを渡せます
squashnumber比率0.15潰れ量の最大値。0.2なら最も潰れた瞬間に高さが80%になります
stiffnessnumberradian/秒25.0元の形へ戻る速さ
dampingnumber1/秒12.0振動が収束する速さ

戻り値 ​

型単位内容
number倍率stretchX。X方向の伸縮率
number倍率stretchY。Y方向の伸縮率。stretchXとは体積を保つよう逆数の関係になります
numberbounds_heightに対する比率offsetCorrection。潰れて縮んだ分だけ接地位置がずれるのを補正する値です。bounds_heightに掛けてoffset_yへ加算します

squash の名前と意味は mt.bounce_* の squash と共通です。

使用例 ​

lua
-- 衝突時刻を自分で決めて潰れを適用する

    t = ctx.time,
    impact_time = landTime,
    squash = 0.2,
})

character.stretch_y = sy
character.offset_y = character.offset_y + correction * character.geometry.bounds_height

TIP

衝突速度に応じて潰れ具合を変えたい場合は、squash 自体を計算してください。 速度を直接渡す引数は用意していません。速度を素直に掛ける方式では、速度が少し大きいだけで 潰れ量が下限に張り付き、それ以上速くしても絵が変わらなくなるためです。下記のように 「どの速度で最大まで潰れるか」を明示するほうが、意図した範囲に収まります。

lua
local squashAmount = 0.3 * mt.saturate(impactSpeed / kFullSquashSpeed)
local sx, sy, correction = mt.impact_squash({ t = ctx.time, impact_time = landTime, squash = squashAmount })

APIレベル: 3+

摩擦による指数減速を計算します。「勢いよく入ってスーッと止まる」動きを、到達時間ではなく初速と摩擦係数という物理量で制御できます。

引数 ​

引数型単位省略時内容
tnumber秒指定必須経過時間。負値は0として扱います
speednumbercanvas正規化変位/秒指定必須初速
frictionnumber1/秒0.0減衰率。大きいほど早く止まります

戻り値 ​

型単位内容
numbercanvas正規化変位distance。それまでに進んだ距離
numbercanvas正規化変位/秒currentSpeed。その時点での速度

最終的な移動距離は speed / friction に収束します。逆にいえば、止まってほしい距離が決まっているなら speed = distance * friction と置けます。

mt.ease.out_expo との使い分け: イージングは「決まった時間で 0→1 を進む」進行度なのに対し、こちらは初速と摩擦が独立した物理量なので、初速だけを変えて減速の質感は揃えるといった調整ができます。

使用例 ​

lua
-- 左から滑り込んで摩擦で止まる
local travelled = mt.friction_decay(ctx.time - startTime, 2.0, 4.0)
character.offset_x = 0.5 - 0.5 + travelled

NOTE

friction が極めて小さい（1e-4 以下）場合は等速直線運動として扱います。数式上の桁落ちを避けるためで、実用上は摩擦なしと同じ挙動です。

10. イージング ​

APIレベル: 1+

mt.ease.<name>(t) は進行度 t(通常0–1)を受け取り、緩急のついた進行度を返します。 mt.stagger や mt.cycle が返す直線的な進行度に表情を付けるのが典型的な使い方です。 mt.ease.cubic_bezierを除き、入力tは自動でクランプされません。0–1に制限する場合は、 mt.saturateを通してから渡してください。

名前は「カーブの種類」と「向き」の組み合わせです。

  • in_ — 加速(ゆっくり始まり、速く終わる)。退場向き
  • out_ — 減速(速く始まり、ゆっくり止まる)。登場向き
  • in_out_ — 前半加速・後半減速
カーブ関数名特徴
Linearlinear等速(変化なし)
Quadin_quad / out_quad / in_out_quad最も緩やかな加減速
Cubicin_cubic / out_cubic / in_out_cubic標準的な加減速。迷ったらまずこれ
Quartin_quart / out_quart / in_out_quartCubicより急峻
Sinein_sine / out_sine / in_out_sineサイン波由来のごく緩やかな緩急
Circin_circ / out_circ / in_out_circ端で急激に立ち上がる円弧カーブ
Expoin_expo / out_expo / in_out_expo指数的な非常に強い緩急
Backin_back / out_back / in_out_back一度行き過ぎてから戻る(0–1の外へはみ出す)
Elasticin_elastic / out_elastic / in_out_elasticバネのように振動しながら収まる(0–1の外へはみ出す)
Bouncein_bounce / out_bounce / in_out_bounce床で弾むようなバウンド

14. パス上への整列 ​

mt.layout.queue_on_path(ctx, path, options?) ​

APIレベル: 3+

mt.path.arc_lengthで作ったパス上に、文字（またはパーツ）を読み順のまま並べ、各要素が 占める距離比（0–1）を返します。

間隔はホストが実際に組版した原点の間隔から求めます（mt.layout.reflowと同じ方式）。 そのためtracking・文字ごとのmargins・カーニングといったパラメータ設定が、そのまま パス上の字送りに反映されます。options.gapはそれに上乗せする追加間隔なので、gapが 0ならホストの字送りどおりに並びます。

引数 ​

引数型単位省略時内容
ctxtable—指定必須OnLayoutのコンテキスト
pathtable—指定必須mt.path.arc_lengthの戻り値
optionstable—nil配置方法の設定
options.alignstring—"end"文字列を置く位置。"end"、"start"、"center"を指定します
options.gapnumbercanvas幅比0.0ホストの字送りへ上乗せする追加間隔
options.modestring—"horizontal"ホストの組版方向。"horizontal"または"vertical"
options.target_typestring—"character"対象の種類。"character"または"part"
options.targetstable—全要素読み順に並べた対象index配列

戻り値 ​

型単位内容
table0–1ctx.charsまたはctx.partsと同じindexで、各要素が占めるパス上の距離比を取得できるslots配列

slotsはアニメーションの進行度ではなく、パス上の位置を表します。

進行方向と読み順 ​

スロットは進行方向に沿った距離の昇順で割り当てられます。基準は画面の左右ではなく パスの進行方向です。targetsを省略した場合はindexの昇順に割り当てるため、パスが 左から右へ進むならそのまま画面上の読み順になります。

IMPORTANT

右から左へ進むパスでは、距離の昇順が x の減少方向になります。 そのためtargetsを 省略すると文字1が最も右、文字Nが最も左に置かれ、画面上では文字列が逆転して見えます。 左から右に読める配置にしたい場合は、targetsを読み順の逆で渡してください。

lua
-- 右から左へ進むパスで、画面上の読み順を保つ
local targets = {}
for index = ctx.char_count, 1, -1 do
    targets[#targets + 1] = index
end
local slots = mt.layout.queue_on_path(ctx, path, { targets = targets })

これはトレードオフであり、逆向きパスでは次の2つを同時には満たせません。どちらを取るかは 用途によって選んでください。

targets画面上の並び隊列の先頭
省略（index昇順）逆転（右→左に読む）文字1
読み順の逆正しい（左→右に読む）最後の文字

alignも同様に進行方向基準です。"end"はパスの終端に文字列の末尾を置くため、 右から左へ進むパスでは末尾が画面の左側に来ます。

パスの向きalign = "end"で末尾が来る位置
左→右画面右側
右→左画面左側

使用例 ​

lua
-- 用途1: パスに沿ってテキストを並べる（静止）
local path = mt.path.arc_length(kPathPoints, ctx.canvas.aspect_ratio)
local slots = mt.layout.queue_on_path(ctx, path, { gap = 0.004 })
for index = 1, ctx.char_count do
    local x, y, heading = path:at_distance(slots[index])
    ctx.chars[index].rotation = heading
    mt.layout.place_2d(ctx, ctx.chars[index], x, y)
end
lua
-- 用途2: パスを走って自分のスロットで停止する（隊列がブレーキ）
local path = mt.path.arc_length(kPathPoints, ctx.canvas.aspect_ratio)
local slots = mt.layout.queue_on_path(ctx, path, { align = "end" })
local progress = mt.ease.out_cubic(mt.saturate(ctx.time / 3.2))
for index = 1, ctx.char_count do
    -- math.minが隊列の停止そのもの: 先頭は終端まで、後続は自分の位置で止まる
    local x, y, heading = path:at_distance(math.min(progress, slots[index]))
    ctx.chars[index].rotation = heading
    mt.layout.place_2d(ctx, ctx.chars[index], x, y)
end

NOTE

文字列の総長がパス全長を超える場合、距離比が0と1にクランプされ、文字同士が重なります。 長いテキストを短いパスに載せる場合は、path:length()で収まるか確認してください。

15. モーションパス ​

制御点に沿って「流れ込むように登場する」「弧を描いて着地する」といった動きを表現する 曲線評価APIです。

座標系は決め打ちされていません。点は単なる { x, y } テーブルで、呼び出し側が 渡した座標系(offsetの正規化座標、canvas px、文字ローカル座標など)をそのまま受け取り、 同じ座標系の値を返します。

NOTE

戻り値を offset_x / offset_y に直接代入するときは、点も offset の単位 （中立値 0.5 のcanvas正規化変位）で置いてください。 下記の例は着地点を { x = 0.5, y = 0.5 }（変位ゼロ）にしているため、character.offset_x = x がそのまま 自然位置への着地になります。canvas 絶対座標や 0 始まりの局所座標を渡したまま offset に代入すると、意図しない位置に飛びます。

いずれの関数も戻り値は x, y, tangentX, tangentY の4つです。tangentX / tangentY は 正規化されていない生の微分値(進行速度も含む)で、進行方向の角度が欲しい場合は math.deg(math.atan(tangentY, tangentX))、単位ベクトルが欲しい場合は local length = math.sqrt(tangentX^2 + tangentY^2) で割ってください。

aspectRationumber—1.0X方向の距離へ掛けるアスペクト比。通常はctx.canvas.aspect_ratioを渡します
optionstable—nil曲線の種類を指定する設定
options.kindstring—"catmull_rom""catmull_rom"または"bezier"

戻り値 ​

型単位内容

メソッド戻り値単位内容

制約・エラー ​

  • options.kind = "bezier"では、pointsにちょうど4個の点が必要です。
  • options.kindには"catmull_rom"または"bezier"を指定します。

    local ratio = mt.distribute(index, ctx.char_count)
    local x, y, heading = path:at_distance(ratio)
    ctx.chars[index].rotation = heading
    mt.layout.place_2d(ctx, ctx.chars[index], x, y)

静的なSVG文字列は関数の外側で mt.svg_path に変換して local 変数へ保持すると、 毎フレームの再解析を避けられます。

        evaluate = function(segmentCtx, previousValue)
            return bounceAnimation(segmentCtx, previousValue)
        end,
    },
})

区間コンテキスト ​

segmentCtxは呼び出し元のctxからcanvas、global、chars、partsなどを引き継ぎ、時間関係だけを 現在区間へ置き換えたコンテキストです。mt.timeline.progressなど、ctxを読み取る既存の Level 3 APIへ通常のctxと同じように渡せます。

フィールド型単位内容
segmentCtx.timenumber秒区間開始からの時間
segmentCtx.framenumberframe区間開始からのフレーム数
segmentCtx.fpsnumberfps呼び出し元と同じフレームレート
segmentCtx.timeline.duration_secondsnumber秒区間の論理duration
segmentCtx.timeline.duration_framesnumberframe区間の論理durationをフレーム換算した値
segmentCtx.timeline.progressnumber0–1区間内の進行度

区間の形式 ​

各区間は次のいずれかの形式です。

区間指定動作
固定長アニメーション{ duration = 秒数, evaluate = 関数 }evaluate(segmentCtx, previousValue) の戻り値を使用
固定長保持{ hold = 秒数 }関数を呼ばず、直前の値を保持
可変長アニメーション{ duration = "remaining", evaluate = 関数 }固定区間を除いた残りのクリップ尺を使用
可変長保持{ hold = "remaining" }残りのクリップ尺で直前の値を保持

"remaining"は1つのchain内で1区間だけ指定できます。その後ろに固定長のアウトロを置くと、 可変区間だけがクリップ尺の変更を吸収し、アウトロは常にクリップ終端で完了します。

lua
local state = mt.timeline.chain(ctx, initialState, {
    { duration = 1.0, evaluate = evaluateIntro },
    { duration = 1.2, evaluate = evaluateBounce },
    { duration = "remaining", evaluate = evaluateIdle },
    { duration = 0.6, evaluate = evaluateOutro },
}, {
    fallback_duration = 6.0,
})

固定区間の合計がクリップ尺を超える場合は、すべての固定区間を比例圧縮します。 segmentCtx.timeとsegmentCtx.timelineは宣言したdurationへ再マッピングされるため、 短いクリップでも各アニメーションは終端状態まで到達します。タイムライン取得不可時は options.fallback_duration（既定 4.0 秒）を仮想クリップ長としてループします。

制約・エラー ​

  • ctx.timeは数値、segmentsとoptionsはtableである必要があります。
  • 各区間はdurationまたはholdのどちらか一方だけを指定します。
  • duration区間にはevaluate関数が必要で、hold区間には指定できません。
  • 区間長には有限の0以上の数値または"remaining"を指定します。
  • "remaining"を指定できる区間は1つだけです。
  • options.fallback_durationは有限の正数である必要があります。

IMPORTANT

evaluateは過去区間の終端値を得るため同じフレーム内で再評価されます。ctxやcharacterを 直接変更せず、引数から計算した値を返す純粋関数として記述し、最終結果だけを適用してください。 mt.bounce_groundのようにitemを直接変更するAPIではなく、値を返すmt.bounce_yなどを segmentCtx.timeと組み合わせて使用します。

mt.layout.canvas_to_offset(resolvedGlobal, canvasWidth, canvasHeight, naturalCenterX, naturalCenterY, canvasX, canvasY) 非推奨 ​

APIレベル: 1+

CAUTION

API Level 1互換関数です。globalの2D変形しか逆算しません。新規コードでは mt.layout.place_2dを使用してください。

文字・パーツの自然中心を、2Dのglobal変形までを考慮したcanvas上の目標位置へ移す offsetを求めるときに使います。offset_x / offset_y は「自身の自然な位置からの変位量」であり ctx.global(position / rotation / scale / stretch / pivot)による全体変形の前の座標系にあるため、目標のcanvas座標を そのまま offset_x = canvasX のように代入しても、ctx.global が初期値のときしか意図した 画面位置になりません。全体を回転・移動・拡大している場合、その変形の分だけ実際の位置が ずれます。この関数は ctx.global の2D変形を打ち消した上で、目標のcanvas位置に対応する offset_x / offset_y を計算します。

引数 ​

引数型単位省略時内容
resolvedGlobaltable—指定必須OnPreLayoutで確定済みのctx.global
canvasWidth / canvasHeightnumberpx指定必須ctx.canvas.widthとctx.canvas.height
naturalCenterX / naturalCenterYnumbercanvas正規化位置指定必須対象の自然中心。文字ではgeometry.bounds_center_x/y、パーツではgeometry.canvas_center_x/y
canvasX / canvasYnumbercanvas正規化位置指定必須配置先の座標

戻り値 ​

型単位内容
numbercanvas正規化変位offsetX
numbercanvas正規化変位offsetY

制約・エラー ​

この関数が反転するのはposition_x/y、rotation、scale、stretch_x/y、 pivot_x/yだけです。文字・パーツの個別rotation/pivot、所有文字からパーツへの階層変形、 global/個別の3D値、camera、projection、Deformは反転しません。幅・高さおよび global.scale * stretch_x/yは非ゼロでなければなりません。

使用例 ​

lua
-- 2D ctx.global.rotation / position_x などを OnPreLayout で変更していても、
-- 個別/3D/Deform変形がなければ自然中心は canvas 上の (0.8, 0.3) に来る
local geometry = character.geometry
character.offset_x, character.offset_y = mt.layout.canvas_to_offset(
    ctx.global, ctx.canvas.width, ctx.canvas.height,
    geometry.bounds_center_x, geometry.bounds_center_y,
    0.8, 0.3
)

注意事項 ​

パーツの場合、パーツ自身の変形(part.offset_x/y 等)は 所有文字の解決済み変形の 内側に重ねて適用されるため、この関数は「文字の変形を無視して canvas 上の固定位置に 置く」ことはできません(文字自体が動いていれば、パーツも一緒に動きます)。パーツを 文字の変形とは独立に canvas 上の固定位置へ置きたい場合は、まずその文字の offset_x/y / rotation / scale 等を確認し、パーツ側の変位量にその逆変形を 別途適用する必要があります。
